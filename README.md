# La Maledizione di Strahd

Diario della campagna di D&D, pubblicato con GitHub Pages.

- `index.html`: grafica e struttura del sito (non va toccata per gli aggiornamenti).
- `data.json`: contenuti del diario. Ogni lunedì mattina un'attività programmata di Claude lo aggiorna con le sessioni registrate su Wispr Flow nella settimana precedente.
